# 时尚造型师 - Fashion Styling App

一个采用京东电商风格设计的个性化时尚造型应用，帮助用户获得专业的穿搭建议。

## 🎨 功能特性

### 欢迎界面
- 简洁优雅的欢迎屏幕
- 专业的服务介绍："Get your personalized fashion styling"
- 京东风格的红色主题设计

### 用户信息表单
- **个人信息收集**：
  - 姓名（必填）
  - 邮箱地址（必填，带邮箱格式验证）
  
- **风格偏好选择**：
  - Casual & Comfortable（休闲舒适）
  - Business Professional（商务专业）
  - Trendy & Fashion-forward（时尚前卫）
  - Classic & Elegant（经典优雅）
  - Bohemian & Artistic（波西米亚艺术）
  - Sporty & Active（运动活力）
  - Minimalist & Clean（极简干净）
  - Vintage & Retro（复古怀旧）
  
- **其他偏好描述**：
  - 可选的文本输入区域
  - 支持详细的风格要求描述

- **照片上传功能**：
  - 支持上传1-3张全身照片
  - 仅接受图片格式文件
  - 拖拽上传支持
  - 实时预览功能

### 提交处理
- "Get My Styling Report" 按钮
- 表单验证（必填项检查）
- 照片上传验证
- 成功提交反馈

## 🎯 设计风格

### 京东电商风格特色
- **主色调**：京东红色 (#E1251B)
- **布局**：简洁现代的卡片式设计
- **字体**：中英文友好的字体栈
- **动效**：平滑的渐变和过渡效果
- **响应式**：完美适配手机、平板、桌面

### UI 库选择
使用 **Ant Design (antd)** 作为UI组件库：
- ✅ 中国用户习惯的设计语言
- ✅ 完整的电商级组件生态
- ✅ 专业的表单和上传组件
- ✅ 易于定制的主题系统

## 🚀 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm start
```
应用将在 [http://localhost:3000](http://localhost:3000) 打开

### 构建生产版本
```bash
npm run build
```

## 📱 响应式设计

- **桌面端**：1200px以下居中布局，双列表单
- **平板端**：768px以下单列布局，优化间距
- **手机端**：480px以下紧凑布局，全宽按钮

## 🔧 技术栈

- **前端框架**：React 19.1.0
- **UI 组件库**：Ant Design
- **图标库**：@ant-design/icons
- **样式**：CSS3 + Flexbox + Grid
- **构建工具**：Create React App

## 📦 项目结构

```
src/
├── App.js          # 主应用组件
├── App.css         # 主样式文件
├── index.js        # 应用入口
└── index.css       # 全局样式
```

## 🎨 自定义主题

应用已配置京东风格的主题色：
- 主色：#E1251B（京东红）
- 辅助色：#C81623（深红）
- 背景色：#f5f5f5（浅灰）
- 文字色：#262626（深灰）

## 🔄 后端集成

应用设计为前端项目，保留后端端口集成：
- 表单数据通过 `onFinish` 函数处理
- 文件上传列表通过 `fileList` 状态管理
- 可轻松对接RESTful API或GraphQL

## 📝 使用说明

1. 用户在欢迎页面了解服务
2. 填写个人基本信息（姓名、邮箱）
3. 选择喜欢的风格类型
4. 上传1-3张全身照片
5. 提交表单获取个性化造型报告
